# معراج نتورك — تقرير تطبيق أندرويد ودليل الاستخراج (Capacitor v7)

تطبيق أندرويد جاهز داخل المشروع (قشرة أصلية تُغلّف واجهة الويب نفسها). البناء النهائي
(APK/AAB) يتم على جهازك لأن بيئة الخادم لا تحتوي على Android SDK.

- **معرّف التطبيق:** `network.meraaj.app` — **الاسم:** «معراج نتورك»
- **الهوية:** كحلي `#0A2540` / ذهبي — شاشة بداية وأيقونة مولّدة بالهوية.
- **مجلد المشروع الأصلي:** `frontend/android/` (Capacitor v7).

---

## ما الجديد المُضمَّن في هذا الإصدار
التطبيق يغلّف بناء الويب (`webDir: build`)، لذا **كل تحديثات الويب الأخيرة تظهر تلقائياً في تطبيق أندرويد بعد `yarn build` + `npx cap sync`**:

1. **تسعير الغرف واختيار الغرفة عند الحجز** — اختيار نوع الغرفة يحسب السعر ديناميكياً (بالغ/طفل/رضيع).
2. **معالجة أسعار رحال الموحّدة** — دعم كائنات `{adult,child,infant}` للصافي/العمولة/العميل بلا أخطاء NaN أو صفر.
3. **فلاتر السوق الاحترافية** — نطاق سعر، تاريخ الانطلاق، مدة الرحلة، مميزات سريعة، وترتيب (شامل «الأكثر مبيعاً»).
4. **تصفّح السوق للزوار** — عرض البرامج قبل تسجيل الدخول، ويُطلب الدخول فقط عند الحجز.
5. **قفل الجلسة عند الخمول (15 دقيقة)** + استعادة الصفحة بعد إعادة الدخول + الرفرش الكامل يعيد للوحة التحكم.
6. **تحسين الصور تلقائياً** — تصغير حتى 1200px وضغط WebP (~82%) عند الرفع + صورة بديلة عند فشل التحميل.
7. **تصميم متجاوب كامل** — يعمل على كل مقاسات الأندرويد (320–430px) بلا تمرير أفقي أو تداخل.
8. **عمود وزر واتساب** في لوحة الأدمن + **زر إعادة مزامنة الأسعار الجماعية**.
9. **إصلاحات تكامل رحال:** `package.updated` (بلا status) يعيد إظهار الباقة، `is_active`/`status` افتراضياً، وتوقيع HMAC مضغوط مطابق لـ JSON.stringify (حل 401).

## المرحلة 1 الأصلية (القشرة الأصلية)
- **زر الرجوع (Back):** تنقّل صفحة-بصفحة عبر React Router؛ في الرئيسية ضغطة ثانية خلال 1.8ث للخروج (`src/native/useAndroidBackButton.js`).
- **شريط الحالة + شاشة كاملة + سبلاش** (`src/native/useNativeChrome.js`).
- **سلاسة اللمس:** إزالة تأخير 300ms، منع الارتداد الزائد، دعم `safe-area`.
- كل الكود الأصلي محميّ بـ `Capacitor.isNativePlatform()` فلا يؤثّر على نسخة الويب.

## المتطلبات على جهازك
- Node.js 18 أو 20 (الحزم على Capacitor **v7**)
- Android Studio + Android SDK (Platform API 24+)
- Java JDK 17

## دليل الاستخراج / البناء

### 1) تجهيز الويب ومزامنته مع أندرويد
```bash
cd frontend
yarn install
yarn build              # يبني ملفات الويب في build/
npx cap sync android    # ينسخ build/ إلى مشروع أندرويد ويحدّث الإضافات
```

### 2) استخراج APK للتجربة (عبر الطرفية)
```bash
cd frontend/android
./gradlew assembleDebug
# الناتج: frontend/android/app/build/outputs/apk/debug/app-debug.apk
```
انسخ `app-debug.apk` إلى هاتف أندرويد وثبّته (فعّل «تثبيت من مصادر غير معروفة»).

### 3) فتح المشروع في Android Studio (اختياري)
```bash
cd frontend
npx cap open android    # ثم اختر جهازاً/محاكياً واضغط Run
```

### 4) بناء نسخة الإصدار للمتجر (AAB موقّعة)
```bash
cd frontend/android
./gradlew bundleRelease
# الناتج: frontend/android/app/build/outputs/bundle/release/app-release.aab
```
> يتطلب إنشاء مفتاح توقيع (keystore) وربطه في `android/app/build.gradle` أو عبر
> Android Studio: Build → Generate Signed Bundle/APK. هذا الملف يُرفع إلى Google Play.

### 5) إعادة توليد الأيقونة/السبلاش (عند تغيير الهوية)
```bash
cd frontend
npx capacitor-assets generate --android   # يقرأ assets/icon-only.png و assets/splash.png
```

## نقاط مهمة
- التطبيق يستدعي الـ backend عبر `REACT_APP_BACKEND_URL` (HTTPS). لا تضع أي أسرار في الواجهة.
- بعد أي تحديث للكود: أعِد `yarn build` ثم `npx cap sync android` قبل البناء لتضمين آخر التغييرات.
- **المراحل القادمة (متوقّفة بطلبك):** إشعارات Firebase FCM (تحتاج مشروع Firebase + `google-services.json`)، وتحديثات OTA عبر Capgo (تحتاج حساب Capgo + مفتاح) — لتحديث المحتوى دون إعادة رفع للمتجر.
