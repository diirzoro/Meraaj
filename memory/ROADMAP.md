# ROADMAP — Meraaj Network (محدّث 2026-06)

## مكتمل
- النواة المحاسبية (Phases 1–11A) + Batch 1 (تكامل الأحداث المالية) + Batch 2 (RBAC/نطاق/واجهات/كشف المكتب/القائمة).
- Meraaj Mobile — المرحلة الأولى: القشرة الأصلية، المصادقة، الرئيسية، التنقل، العمرة، المحفظة/الشحن، الحجوزات، الإشعارات، كشف المكتب، حسابي.

## P0 — قبل النشر التجريبي (Controlled Test Deployment)
1. تشغيل `POST /accounting/chart/seed` على بيئة الاختبار وربط الحسابات الدلالية (`cash`, `bank`, `office_wallet_liability`, ...) من شاشة «ربط الحسابات» — بلا أرقام حسابات في الكود.
2. توليد الفترات المحاسبية للسنة الجارية وتحديد العملة الأساسية.
3. إسناد الأدوار المحاسبية للموظفين الفعليين + تحديد نطاق الحسابات لأمين الصندوق.
4. تفعيل الرقابة المزدوجة للعمليات المطلوبة فعلاً (سند صرف/ترحيل/إقفال) حسب سياسة الإدارة.

## P1 — التالي
- إشعارات Push للجوال (FCM/APNs) + ربطها بأحداث: تأكيد الحجز، تغيير الحالة، اعتماد الشحن، إصدار التذكرة.
- رفع إيصال الشحن كصورة من الجوال (كاميرا/معرض) عبر تخزين كائنات بدل رابط نصي.
- تصدير PDF/CSV للتقارير المحاسبية وكشف حساب المكتب.
- إعادة تعيين كلمة المرور الذاتية (Endpoint + شاشة الجوال الجاهزة للربط).

## P2 — مؤجّل بقرار
- التذاكر: `Search → Trip → Seat → Passenger → Price Check → Booking → Issue → Cancel/Refund` بعد استلام عقد شركة النقل (لا تخمين، لا مزوّد في الكود).
- ACC-009 إعادة تقييم العملات · ACC-010 تقارير موحّدة للعملات · ACC-011 اختبار حمل إنتاجي · ACC-012 ترحيل العملة الأساسية تاريخياً.
- ترحيل/مطابقة البيانات المحاسبية التاريخية (Cutover).
- الاعتراف الزمني المتقدّم بإيرادات الإعلانات.

## تحديث بعد جلسة الإغلاق (2026-06)
### تهيئة مطلوبة قبل النشر التجريبي (لم تُنفَّذ على الإنتاج بقرار)
1. زرع الدليل المحاسبي + ربط الحسابات الدلالية + توليد الفترات + تحديد العملة الأساسية.
2. إسناد الأدوار المحاسبية ونطاقات الحسابات للموظفين الفعليين وتفعيل الرقابة المزدوجة المطلوبة.
### إعداد خارجي مطلوب (EXTERNAL CONFIGURATION)
- FCM (أندرويد) / APNs (iOS) لتشغيل الإشعارات الفورية — المعمارية وتسجيل التوكنات جاهزة.
- مزوّد بريد/SMS لتسليم رمز إعادة تعيين كلمة المرور تلقائياً (حالياً عبر الإدارة).
- عقد API شركة النقل (الطلب الجاهز في `TRANSPORT_API_REQUIREMENTS.md`) لبناء قسم التذاكر.
### مؤجّل للويب بقصد (تقليل مخاطر الجوال)
- الإقفال السنوي وإعادة فتح السنة · إدارة هيكل الدليل (إضافة/حذف الحسابات) · إدارة العملات وأسعار الصرف · إدارة الصلاحيات والنطاقات · الإعلانات والتقارير التشغيلية والنسخ الاحتياطي والصيانة.
