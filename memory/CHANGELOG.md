- مُطبَّق في الخادم على: قائمة الدليل، الشجرة، الحساب بالكود/المعرّف، التعديل/التفعيل/الحذف، الأستاذ، السندات، القيود اليدوية. تمرير كود حساب يدوياً لا يوسّع النطاق.

**السندات المحاسبية (`accounting/vouchers.py`)**: سند قبض/صرف يُرحَّل عبر النواة فقط (`accounting_vouchers` + قيد بمفتاح `voucher:{id}`)، الصلاحية لكل نوع على حدة، تسجيل منفصل لـ created/approved/posted/cancelled by (معرّف موثّق لا اسم من الواجهة)، الإلغاء بقيد عكسي لا تعديل/حذف، ومنع الاعتماد الذاتي.

**كشف حساب المكتب (`office_statement.py`)**: تجاري بحت من `db.transactions` + المحفظة، رصيد افتتاحي/جاري/ختامي وتصنيف عربي للحركات، وعزل صارم (مستخدم المكتب مثبّت على مكتبه مهما أرسل).

## 2026-06 — MERAAJ MOBILE: قشرة تطبيق أصلية (المرحلة الأولى مكتملة)
**البنية**: Capacitor + قشرة موبايل مستقلة تماماً داخل نفس مشروع React على مسارات `/m/*` — بلا Layout/Sidebar الإدارة، وبلا WebView لصفحات الموقع، وبلا باك-إند أو محفظة أو حجوزات موازية.
- `mobile_api.py` (`/api/v1/mobile`): `config` (بوابة الإصدار قبل الدخول)، `bootstrap` (تبويبات/خدمات/أعلام ميزات/شارات/محفظة — Server-driven بطلب واحد)، `home`، `tickets/providers`. طبقة قراءة فقط ومشتقة، لا تحسب مالاً.
- `mobile/api/client.js`: طبقة API واحدة؛ إعادة المحاولة للقراءات فقط (502/503/504) ولا تُعاد أي كتابة (لا حجز/شحن مكرر).
- الشاشات: Splash، Login، Register، Forgot (يوجّه للمسار الحقيقي بلا API وهمي)، Home (بطاقات خدمات + رصيد + برامج + أحدث حجوزات)، برامج العمرة (بحث/تصفية/ترتيب) → تفاصيل → حجز (مسافرون → مراجعة → تأكيد)، حجوزاتي (مركز موحّد قابل لأنواع أخرى) → تفاصيل + مسار، المحفظة (حركات/طلبات شحن/سحوبات)، شحن الرصيد، الإشعارات، مبيعاتي، كشف حساب المكتب، حسابي، التذاكر (مكان + عقد API المطلوب فقط).
- Bottom Navigation بخمسة تبويبات مع شارات من `bootstrap`، Bottom Sheets، Skeletons، Empty/Error states، RTL أولاً، بلا جداول سطح مكتب.
- حسابات الإدارة تُحوَّل إلى لوحة الويب: لوحة الإدارة/المحاسبة لا تُنسخ إلى التطبيق.
- APIs المعاد استخدامها: `/auth/login|register|logout`, `/packages`, `/bookings`, `/wallet/*`, `/notifications`, `/office-statement`.
- مؤجّل: حجز التذاكر (بانتظار عقد شركة النقل)، Push Notifications (العلم موجود والنقل غير موصول)، إعادة تعيين كلمة المرور الذاتية (لا Endpoint بعد).
