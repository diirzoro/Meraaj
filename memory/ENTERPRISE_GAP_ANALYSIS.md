## 1) الملاحظة الجوهرية

## 6) تقرير Scanner (أولي)
- الزر الحالي: `TravelerDocs.js` → `<input type="file" accept="image/*" capture="environment">`.
- سبب فتح File Browser: `capture` سمة للجوال؛ يتجاهلها متصفح الويندوز.
- لا متصفح يدعم TWAIN/WIA مباشرة. الحل: **Meraaj Scan Bridge** — خدمة ويندوز (.NET + WIA/TWAIN)
  على `https://127.0.0.1:8787`: قائمة الأجهزة + بدء المسح (DPI/ألوان/وجهين/ورق) + إرجاع الصفحات → دمج PDF.
- الأمان: CORS مقيّد بنطاق معراج + Token اقتران لمرة واحدة + بلا وصول للقرص.
- يحتاج مُثبّت MSI صغير مرة واحدة على أجهزة الموظفين.
- التوصية: الإبقاء على «رفع ملف» و«تصوير»، وإضافة زر ثالث «مسح من Scanner» يظهر فقط عند عمل الخدمة.
